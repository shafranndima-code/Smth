# Pretty HUD (Fabric, Minecraft 1.21.11)

Чисто визуальный клиентский мод: без читов, ничего не отправляет на сервер.

## Что внутри
- Мини-HUD: плашка зелий (компактная), FPS/пинг, броня с прочностью. Перетаскивание, масштаб, прозрачность.
- Меню (Right Shift): вкладки Интерфейс / Эффекты / Темы, 14 тем + своя тема из двух цветов.
- Нимб над головой (3-е лицо): двухцветный бегущий градиент, блик, внутреннее кольцо, искорки.
- Частицы в небе: звёзды / снег / светлячки / цвет темы / падающие звёзды.
- Обводка цели ТОЛЬКО под прицелом (сквозь стены не работает): плавно переливается цветами темы + светящееся кольцо под целью.

## Сборка
1. Нужны JDK 21 и интернет.
2. В папке проекта: `gradle wrapper --gradle-version 9.2.1` (один раз), затем `./gradlew build`
   (на Windows: `gradlew.bat build`).
3. Готовый jar: `build/libs/prettyhud-1.0.0.jar` (не *-sources.jar) -> в папку `mods`.
4. Нужен Fabric Loader 0.18+ и Fabric API 0.141.3+ для 1.21.11.

Конфиг: `config/prettyhud.json`.

## Важно
Код написан без возможности скомпилировать его против Minecraft 1.21.11. Если сборка выдаст
ошибки "cannot find symbol", скорее всего в 1.21.11 переименован метод. Пришли текст ошибки — поправлю.
Самые вероятные места: `MenuScreen`/`HudEditorScreen` (события мыши MouseButtonEvent),
`PrettyHudClient` (KeyMapping.Category), `HudRenderer` (HudElementRegistry, Identifier).
